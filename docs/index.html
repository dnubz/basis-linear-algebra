CHAPTER 01 / GAUSS–JORDAN

Clear the rows.
Reveal the solution.

Gauss–Jordan elimination solves a linear system by transforming its augmented matrix into reduced row echelon form.

The methodWorked exampleInteractive labSpecial cases & inverses
01 / THE IDEA

Same solutions. Simpler equations.

A linear system with \(m\) equations and \(n\) unknowns is written \(A\mathbf x=\mathbf b\), where \(A\in\mathbb R^{m\times n}\), \(\mathbf x\in\mathbb R^n\), and \(\mathbf b\in\mathbb R^m\). Keep the coefficients and right-hand side together in the augmented matrix \([A\mid\mathbf b]\).

\[\begin{aligned}x+2y&=5\\3x+4y&=11\end{aligned}\quad\longleftrightarrow\quad\left[\begin{array}{cc|c}1&2&5\\3&4&11\end{array}\right]\]

The three legal row operations

01

Swap

\(R_i\leftrightarrow R_j\)

Exchange any two equations.

02

Scale

\(R_i\leftarrow cR_i,\ c\ne0\)

Multiply an entire row by a nonzero number.

03

Replace

\(R_i\leftarrow R_i+cR_j\)

Add a multiple of another row to a row, with \(i\ne j\).

Each operation is reversible, so the solution set stays the same. Always apply the operation to the whole row, including the augmented column.

Your destination: RREF

A matrix is in reduced row echelon form when all four conditions hold:

  1. All rows consisting entirely of zeros are at the bottom.
  2. The first nonzero entry in each nonzero row (its pivot) is 1.
  3. Each pivot is to the right of the pivot in the row above.
  4. Each pivot is the only nonzero entry in its column.
Gauss vs. Gauss–Jordan

Gaussian elimination stops at row echelon form and uses back-substitution. Gauss–Jordan also clears the entries above each pivot. Every matrix has a unique RREF, although the sequence of operations can vary.

The algorithm

  1. Scan columns from left to right. In the remaining rows, find a nonzero pivot entry; swap it into the current row if needed.
  2. Divide the pivot row by its pivot to make a leading 1.
  3. Subtract suitable multiples of that row from every other row to clear the pivot column.
  4. Move one row down and continue to the right. Skip a column when no pivot is available.
  5. Interpret the result: pivot variables, free variables, or a contradiction.
02 / A WORKED EXAMPLE

From equations to an answer.

Solve \(x+2y=5\) and \(3x+4y=11\).

Start
\[\left[\begin{array}{cc|c}1&2&5\\3&4&11\end{array}\right]\]

The first pivot is already 1.

\(R_2\leftarrow R_2-3R_1\)
\[\left[\begin{array}{cc|c}1&2&5\\0&-2&-4\end{array}\right]\]

Clear the entry below it.

\(R_2\leftarrow-\tfrac12R_2\)
\[\left[\begin{array}{cc|c}1&2&5\\0&1&2\end{array}\right]\]

Normalize the second pivot.

\(R_1\leftarrow R_1-2R_2\)
\[\left[\begin{array}{cc|c}1&0&1\\0&1&2\end{array}\right]\]

Clear above it: \(x=1,\ y=2\).

Always check the answer.

\(1+2(2)=5\) and \(3(1)+4(2)=11\). Both original equations are satisfied.

04 / READ THE RESULT

One, none, or infinitely many?

Unique solution

No contradiction, and a pivot in every variable column.

\(\operatorname{rank}(A)=n\)

No solution

A row \([0\ \cdots\ 0\mid c]\), with \(c\ne0\), says \(0=c\).

\(\operatorname{rank}(A)\lt \operatorname{rank}([A\mid b])\)

Infinitely many

A consistent system with at least one free variable.

\(\operatorname{rank}(A)\lt n\)

In general, consistency requires \(\operatorname{rank}(A)=\operatorname{rank}([A\mid\mathbf b])\). For a consistent system, the number of free variables is \(n-\operatorname{rank}(A)\).

Write a parametric solution

\[\left[\begin{array}{ccc|c}1&0&2&3\\0&1&-1&1\\0&0&0&0\end{array}\right]\quad\Rightarrow\quad\begin{cases}x_1=3-2t\\x_2=1+t\\x_3=t\end{cases}\quad(t\in\mathbb R)\]

Equivalently, \(\mathbf x=(3,1,0)^T+t(-2,1,1)^T\). A zero row does not by itself mean infinitely many solutions: check the variable columns and consistency.

Find an inverse with the same method

For a square \(n\times n\) matrix, attach the identity and reduce the left block:

\[[A\mid I_n]\ \longrightarrow\ [I_n\mid A^{-1}]\]

This works exactly when \(A\) has a pivot in every column, or equivalently \(\det A\ne0\). If the left block cannot become \(I_n\), the matrix is singular and has no inverse.

\[A=\begin{bmatrix}1&2\\3&4\end{bmatrix},\qquad A^{-1}=\begin{bmatrix}-2&1\\\frac32&-\frac12\end{bmatrix}\]

Row operations also reveal rank: count the pivots. For the null space, solve \(A\mathbf x=\mathbf0\); its dimension is the nullity. The rank–nullity theorem says \(\operatorname{rank}(A)+\operatorname{nullity}(A)=n\).

Exact math vs. numerical computation

The lab uses exact fractions. With floating-point data, practical solvers use pivoting and tolerances; a very small pivot can amplify rounding errors. For large systems, LU or QR methods are often more efficient than full Gauss–Jordan elimination.

CHAPTER 02 / EIGENVALUES & EIGENVECTORS

Some directions
stay special.

A matrix usually changes a vector’s direction. Eigenvectors are the special nonzero vectors that remain on the same line through the origin.

The definitionWorked examplesVisual explorerThe bigger picture
01 / THE DEFINITION

A transformation, captured in one equation.

\[A\mathbf v=\lambda\mathbf v,\qquad\mathbf v\ne\mathbf0\]

\(A\): the transformation

A square matrix. Eigenvalues are defined for square matrices in this lesson.

\(\mathbf v\): an eigenvector

A nonzero vector whose image is a scalar multiple of itself.

\(\lambda\): an eigenvalue

The scalar factor: stretch, shrink, reverse, or collapse.

If \(\lambda\gt 1\), the vector stretches; if \(0\lt \lambda\lt 1\), it shrinks; if \(\lambda\lt 0\), it reverses direction and scales by \(|\lambda|\); if \(\lambda=0\), its image is the zero vector. If \(\lambda=1\), it stays unchanged. Multiples \(c\mathbf v\) with \(c\ne0\) are also eigenvectors for the same eigenvalue.

How to find the eigenvalues

\[A\mathbf v=\lambda\mathbf v\quad\Rightarrow\quad(A-\lambda I)\mathbf v=\mathbf0\quad\Rightarrow\quad\det(A-\lambda I)=0\]

A nonzero solution exists only when \(A-\lambda I\) is singular. The determinant equation is the characteristic equation. We use \(p_A(\lambda)=\det(\lambda I-A)\); using \(\det(A-\lambda I)\) changes the polynomial by \((-1)^n\), but its roots are the same.

The complete 2 × 2 formula

\[A=\begin{bmatrix}a&b\\c&d\end{bmatrix},\qquad p_A(\lambda)=\lambda^2-(a+d)\lambda+(ad-bc)\]
\[\boxed{\lambda_{1,2}=\frac{\operatorname{tr}(A)\pm\sqrt{\operatorname{tr}(A)^2-4\det(A)}}{2}}\]

Here \(\operatorname{tr}(A)=a+d\) and \(\det(A)=ad-bc\). A positive discriminant gives two distinct real eigenvalues; zero gives a repeated real eigenvalue; negative gives a complex-conjugate pair for a real matrix.

02 / A WORKED EXAMPLE

Find the values. Then the vectors.

Let \(A=\begin{bmatrix}4&1\\2&3\end{bmatrix}\).

1

Build the characteristic equation

\[\det(A-\lambda I)=(4-\lambda)(3-\lambda)-2=\lambda^2-7\lambda+10=(\lambda-5)(\lambda-2)=0\]

The eigenvalues are \(\lambda_1=5\) and \(\lambda_2=2\).

2

For each eigenvalue, solve a homogeneous system

This is where Gauss–Jordan comes back. Reduce \([A-\lambda I\mid\mathbf0]\) and choose a nonzero solution.

\[\lambda=5:\quad\begin{bmatrix}-1&1\\2&-2\end{bmatrix}\longrightarrow\begin{bmatrix}1&-1\\0&0\end{bmatrix}\quad\Rightarrow\quad y=x\]

So \(E_5=\operatorname{span}\{(1,1)^T\}\). Any nonzero multiple of \((1,1)^T\) is an eigenvector.

\[\lambda=2:\quad\begin{bmatrix}2&1\\2&1\end{bmatrix}\longrightarrow\begin{bmatrix}1&\frac12\\0&0\end{bmatrix}\quad\Rightarrow\quad y=-2x\]

So \(E_2=\operatorname{span}\{(1,-2)^T\}\). An eigenspace includes the zero vector, but an eigenvector never does.

3

Verify the result

\[A\begin{bmatrix}1\\1\end{bmatrix}=\begin{bmatrix}5\\5\end{bmatrix}=5\begin{bmatrix}1\\1\end{bmatrix},\qquad A\begin{bmatrix}1\\-2\end{bmatrix}=\begin{bmatrix}2\\-4\end{bmatrix}=2\begin{bmatrix}1\\-2\end{bmatrix}\]
A 3 × 3 example: repeated eigenvalues
\[B=\begin{bmatrix}2&1&0\\0&2&0\\0&0&3\end{bmatrix},\qquad p_B(\lambda)=(\lambda-2)^2(\lambda-3)\]

Triangular matrices have their eigenvalues on the diagonal, counted with multiplicity. For \(\lambda=2\), \((B-2I)\mathbf v=0\) forces \(y=z=0\), so \(E_2=\operatorname{span}\{(1,0,0)^T\}\). Its algebraic multiplicity is 2, but its geometric multiplicity is 1.

For \(\lambda=3\), solving gives \(x=y=0\), so \(E_3=\operatorname{span}\{(0,0,1)^T\}\). There are only two independent eigenvectors in total: \(B\) is not diagonalizable.

04 / THE BIGGER PICTURE

What eigenvalues tell you.

Multiplicity and diagonalization

The algebraic multiplicity of \(\lambda\) is its multiplicity as a root of \(p_A\). Its geometric multiplicity is \(\dim\ker(A-\lambda I)\), the number of independent eigenvectors for that value.

\[1\le\text{geometric multiplicity}\le\text{algebraic multiplicity}\]

An \(n\times n\) matrix is diagonalizable over a field precisely when it has \(n\) independent eigenvectors over that field. Put those vectors in the columns of \(P\), in the same order as the eigenvalues in \(D\):

\[AP=PD,\qquad A=PDP^{-1},\qquad A^k=PD^kP^{-1}\quad(k=0,1,2,\ldots)\]

Distinct eigenvalues guarantee independent eigenvectors. A repeated eigenvalue alone does not decide diagonalizability: \(2I\) is diagonalizable, while \(\begin{bmatrix}2&1\\0&2\end{bmatrix}\) is not. Every real symmetric matrix has an orthonormal eigenbasis and can be written \(A=QDQ^T\), where \(Q^TQ=I\).

Fast checks for any square matrix

\[\sum_{i=1}^{n}\lambda_i=\operatorname{tr}(A),\qquad\prod_{i=1}^{n}\lambda_i=\det(A)\]

Count eigenvalues with algebraic multiplicity, allowing complex roots. A zero eigenvalue is equivalent to singularity. Triangular matrices have the diagonal entries as eigenvalues. Similar matrices \(B=P^{-1}AP\) have the same characteristic polynomial and eigenvalues.

What about complex eigenvalues?

\[R=\begin{bmatrix}0&-1\\1&0\end{bmatrix},\qquad p_R(\lambda)=\lambda^2+1,\qquad\lambda=\pm i\]

A 90° rotation has no real eigenvectors: no real nonzero vector stays on its original line. Over \(\mathbb C\), for \(\lambda=i\), one eigenvector is \((1,-i)^T\); for \(\lambda=-i\), one is \((1,i)^T\). The equation \(A\mathbf v=\lambda\mathbf v\) still applies.

Why this matters

In a discrete system \(\mathbf x_{k+1}=A\mathbf x_k\), an eigenvector component scales by \(\lambda^k\). All initial states tend to zero if every eigenvalue satisfies \(|\lambda|\lt 1\). If any eigenvalue has magnitude greater than 1, some states grow. Magnitude 1 needs more analysis, especially when the matrix is not diagonalizable.

Eigenvectors also identify principal directions in covariance matrices (PCA) and vibration modes in idealized linear models. The same idea appears everywhere: choose coordinates in which the transformation becomes easier to understand.

Common mistakes to avoid

Do not use the zero vector as an eigenvector. Subtract \(\lambda\) only from the diagonal when forming \(A-\lambda I\). Solve a new null-space problem for each eigenvalue. Repeated roots do not automatically give multiple independent eigenvectors.

01 / GAUSS–JORDAN

Row operations & RREF

\[R_i\leftrightarrow R_j\qquad R_i\leftarrow cR_i\ (c\ne0)\]\[R_i\leftarrow R_i+cR_j\quad(i\ne j)\]

RREF: zero rows last; leading entries 1; pivots move right; each pivot is the only nonzero entry in its column.

Method: choose a pivot → swap if needed → normalize → clear its column → move down and right.

Solving \(A\mathbf x=\mathbf b\)

\[r=\operatorname{rank}(A),\quad r'=\operatorname{rank}([A\mid b])\]

\(r\lt r'\): no solution.
\(r=r'=n\): unique solution.
\(r=r'\lt n\): infinitely many solutions, with \(n-r\) free variables.

\[\operatorname{rank}(A)+\dim\ker(A)=n\]

Matrix inverse

\[[A\mid I]\to[I\mid A^{-1}]\]

Exists iff \(A\) is square and \(\det A\ne0\).

02 / EIGENVALUES

Values, vectors & spaces

\[A\mathbf v=\lambda\mathbf v,\quad\mathbf v\ne0\]\[p_A(\lambda)=\det(\lambda I-A)=0\]\[E_\lambda=\ker(A-\lambda I)\]

First solve for \(\lambda\); then row-reduce \(A-\lambda I\) to find a basis of each eigenspace.

For \(A=\begin{bmatrix}a&b\\c&d\end{bmatrix}\)

\[t=a+d,\quad\delta=ad-bc\]\[p_A(\lambda)=\lambda^2-t\lambda+\delta\]\[\lambda_{1,2}=\frac{t\pm\sqrt{t^2-4\delta}}2\]

Discriminant \(\gt 0\): two real roots.
\(=0\): repeated real root.
\(\lt 0\): conjugate complex roots (real \(A\)).

Checks & diagonalization

\[\sum_i\lambda_i=\operatorname{tr}(A),\quad\prod_i\lambda_i=\det A\]\[A=PDP^{-1},\qquad A^k=PD^kP^{-1}\]

Diagonalizable iff there are \(n\) independent eigenvectors over the chosen field. Geometric multiplicity ≤ algebraic multiplicity.

THE SUPPORTING FORMULAS

Determinants & the identity

\[I_n=\operatorname{diag}(1,\ldots,1),\qquad\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc\]
\[\det\begin{bmatrix}a&b&c\\d&e&f\\g&h&i\end{bmatrix}=a(ei-fh)-b(di-fg)+c(dh-eg)\]

Swapping rows changes the determinant’s sign. Scaling one row by \(c\) scales it by \(c\). Adding a multiple of another row leaves it unchanged. A triangular matrix’s determinant is the product of its diagonal entries.
